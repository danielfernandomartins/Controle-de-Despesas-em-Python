# Controle de Despesas em Python

Sistema simples de controle de despesas desenvolvido em Python para praticar lógica de programação, organização de dados e regras básicas de negócio.

## Funcionalidades

- Cadastro de despesas
- Listagem de despesas cadastradas
- Cálculo do total de gastos
- Busca de despesas por categoria
- Menu interativo no terminal

## Conceitos aplicados

- Variáveis
- Listas
- Dicionários
- Funções
- Estruturas condicionais
- Loops
- Entrada e saída de dados
- Conversão de tipos
- Manipulação de strings

## Tecnologias utilizadas

- Python
- Google Colab
- GitHub

## Objetivo do projeto

Aplicar conceitos fundamentais de Python em um cenário financeiro simples, simulando o controle de despesas e a organização de informações por categoria.

## Próximas evoluções

- Edição de despesas
- Exclusão de despesas
- Limite mensal de gastos
- Relatórios por categoria
- Persistência de dados
- Banco de dados
- Testes automatizados
- API REST com FastAPI
